# 客户门户系统

## 项目简介

客户门户系统是一个现代化的外部客户页面，旨在为客户提供便捷的订单管理、文档查看和个人设置功能。系统采用响应式设计，适配不同设备屏幕，提供流畅的用户体验。

## 技术栈

- HTML5
- CSS3 (Tailwind CSS v3)
- JavaScript
- Font Awesome 图标库
- Inter 字体

## 项目结构

```
customer-portal/
├── index.html              # 登录页面
├── dashboard.html          # 数据概览页面
├── orders.html             # 订单列表页面
├── order-detail.html       # 订单详情页面
├── documents.html          # 文档中心页面
├── document-detail.html    # 文档详情页面
├── search.html             # 高级检索页面
├── settings.html           # 个人设置页面
└── README.md               # 项目说明文档
```

## 功能特点

### 1. 登录页面
- 客户代码 + 密码登录
- Azure 单点登录
- DRM系统跳转登录
- 记住登录状态
- 密码错误次数限制
- 异地登录提醒

### 2. 数据概览（Dashboard）
- 欢迎卡片
- 统计概览卡片（订单总数、文档总数、本月新增文档数、最近7天下载次数）
- 最近活动时间线
- 快捷入口按钮

### 3. 我的订单
- 订单列表展示
- 多条件筛选（时间范围、订单状态）
- 支持排序
- 订单详情查看
- 订单关联文档查看

### 4. 文档中心
- 文档列表/卡片视图切换
- 多维度筛选（文档类型、来源系统、时间范围等）
- 批量操作（批量下载、批量收藏）
- 文档预览和下载
- 文档收藏功能

### 5. 高级检索
- 多条件组合检索
- 逻辑操作符支持（AND/OR）
- 检索条件保存
- 检索历史记录
- 结果导出（Excel）

### 6. 个人设置
- 账号信息修改
- 密码修改
- 通知偏好设置
- 下载历史查看
- 收藏文档管理

## 设计风格

- **现代化商务风格**：简洁、专业、高效
- **品牌一致性**：使用公司品牌色彩和标识
- **用户友好**：直观的导航和操作流程
- **响应式设计**：适配不同设备屏幕

## 颜色方案

- **主色调**：深蓝色 (#1a365d) - 代表专业和信任
- **辅助色**：浅蓝色 (#4299e1) - 用于强调和交互元素
- **中性色**：白色、浅灰、中灰、深灰、黑色
- **功能色**：成功绿、警告黄、错误红、信息蓝

## 使用说明

1. 打开 `index.html` 页面进行登录
2. 登录成功后进入数据概览页面
3. 通过左侧菜单或顶部导航栏访问各个功能模块
4. 在移动端，使用底部导航栏进行功能切换

## 注意事项

- 本项目为前端页面展示，实际功能需要与后端API对接
- 所有表单提交和数据操作均为模拟实现
- 响应式设计已针对主流设备进行优化
