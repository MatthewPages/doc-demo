## 2. 角色权限体系

| 角色 | 权限范围 | 说明 |
|------|----------|------|
| 超级管理员 | 全部功能 | 系统最高权限 |
| 文档管理员 | 文档管理、系统对接、统计分析 | 负责文档相关管理 |
| 客户管理员 | 客户管理、权限配置 | 负责客户账号和权限 |
| 审计员 | 统计分析、操作日志 | 只读权限，用于审计 |
| 普通操作员 | 文档补录、文档列表 | 基础操作权限 |

## 3. 管理概览（Dashboard首页）

**功能描述：**
- **数据统计卡片：**
  - 今日文档同步数 / 本周累计
  - 活跃客户数（今日/本周）
  - 待审核文档数
  - 系统运行状态（健康度）
- **图表展示：**
  - 文档趋势图（近7天/30天新增文档）
  - 各系统同步占比饼图
  - 文档类型分布图
  - 客户活跃度Top10
- **实时监控：**
  - 最近同步任务状态
  - 系统告警信息
  - 最近操作日志
- **快捷操作：**
  - 快速上传文档
  - 新建客户
  - 查看同步日志
  - 系统健康检查

## 4. 文档管理

### 4.1 文档列表

**功能描述：**
- 高级筛选：
  - 来源系统（多选）
  - 文档类型（多选）
  - 客户代码
  - 订单号
  - 上传时间范围
  - 文档状态（正常/待审核/已删除）
- 批量操作：
  - 批量删除
  - 批量转移客户
  - 批量更新元数据
  - 批量导出文档信息
- 文档详情查看：
  - 文档预览
  - 完整元数据
  - 版本历史
  - 操作记录
  - 哈希校验

**操作流程：**
1. 筛选或搜索找到目标文档
2. 点击查看详情或批量选择
3. 执行相应操作（预览、下载、编辑、删除等）

### 4.2 文档补录

**功能描述：**
- **手动上传流程：**
  1. 选择上传方式（单文件/多文件/ZIP包）
  2. 填写文档信息：
     - 文档名称（自动识别文件名）
     - 文档类型（必填）
     - 来源系统（手动上传选"手动补录"）
     - 优先级
  3. 填写元数据（支持智能联想）：
     - 订单号
     - 客户代码（必选，支持搜索）
     - 产品代码
     - 项目编码
     - 文档日期
     - 备注
  4. 预览确认
  5. 提交上传（自动生成哈希、建立版本记录）

- **批量导入（Excel）：**
  - 下载导入模板
  - 填写文档信息和元数据
  - 上传Excel文件 + 文档压缩包
  - 系统校验数据
  - 确认导入/下载错误报告

### 4.3 文档审核

**功能描述：**
- 待审核文档列表
- 查看文档内容和元数据
- 审核操作：
  - 通过：文档正式生效，客户可见
  - 驳回：填写驳回原因，退回修改
  - 修改：直接编辑文档信息后通过
- 审核记录留存

## 5. 客户管理

### 5.1 客户列表

**功能描述：**
- 客户信息展示：
  - 客户代码、客户名称（基础信息可从DRM系统同步）
  - 账号状态（正常/禁用/锁定）
  - 关联文档数
  - 最后登录时间
  - 操作（查看、编辑、禁用、重置密码）
- 筛选和搜索：
  - 按状态筛选
  - 按创建时间筛选
  - 关键词搜索（客户代码/名称）
- 批量操作：
  - 批量启用/禁用
  - 批量导出客户信息

### 5.2 客户详情页

**功能描述：**
- **基本信息：**
  - 客户代码、名称、联系人、联系方式
  - 账号状态、创建时间、最后登录时间
  - 登录日志（最近登录记录）

- **权限配置：**
  - 文档访问权限：
    - 按订单范围（全部/指定订单/按时间范围）
    - 按产品范围（全部/指定产品）
    - 按文档类型（可访问的文档类型）
    - 按来源系统（可访问的系统文档）
  - 功能权限：
    - 文档下载权限
    - 文档预览权限
    - 批量下载权限
    - 分享权限
  - 数据权限生效时间范围

- **关联文档：**
  - 该客户所有文档列表
  - 支持快速跳转文档详情

- **操作日志：**
  - 客户所有操作记录（登录、下载、搜索等）

### 5.3 新建/编辑客户

**功能描述：**
- 表单字段：
  - 客户代码（唯一，必填）
  - 客户名称（必填）
  - 联系人
  - 联系电话
  - 邮箱
  - 初始密码（自动生成/手动设置）
  - 账号状态
  - 权限配置（同上）
- 操作：
  - 保存
  - 取消

### 5.4 客户操作日志

**功能描述：**
- 日志内容：
  - 操作时间
  - 操作类型（登录/退出/下载/预览/搜索等）
  - 操作详情
  - IP地址
  - 设备信息
  - 操作结果（成功/失败）
- 筛选和导出：
  - 按客户筛选
  - 按时间范围筛选
  - 按操作类型筛选
  - 导出日志（Excel）

## 6. 系统对接

### 6.1 对接系统配置

**功能描述：**
- 系统列表：
  - 显示已配置的对接系统
  - 状态指示（正常/异常/停用）
  - 操作（编辑、启用/停用、测试连接、查看日志）

- 新建/编辑对接配置：
  - 基本信息：
    - 系统代码（唯一）
    - 系统名称
    - 系统描述
  - 连接配置：
    - 对接模式（推送/拉取/混合）
    - API地址（拉取模式）
    - API Key
    - IP白名单（推送模式）
    - 连接超时设置
  - 元数据映射：
    - 文档类型映射
    - 字段映射配置
  - 同步策略：
    - 拉取频率（定时任务Cron表达式）
    - 增量同步/全量同步
    - 冲突处理策略（覆盖/跳过/告警）

- 测试连接：
  - 一键测试系统连通性
  - 显示测试结果和耗时

### 6.2 同步任务管理

**功能描述：**
- 任务列表：
  - 任务名称
  - 关联系统
  - 任务类型（手动/定时）
  - 上次执行时间
  - 下次执行时间
  - 执行状态（等待/执行中/成功/失败）
  - 操作（立即执行、暂停/恢复、编辑、删除、查看日志）

- 新建同步任务：
  - 任务名称
  - 选择对接系统
  - 同步范围（时间范围/文档类型）
  - 执行方式（立即执行/定时执行）
  - Cron表达式（定时执行）
  - 失败重试策略

- 任务执行日志：
  - 执行时间
  - 执行状态
  - 处理文档数（成功/失败/跳过）
  - 详细日志（可下载）

### 6.3 接口日志监控

**功能描述：**
- 日志查询：
  - 按接口类型筛选（推送/拉取）
  - 按时间范围筛选
  - 按状态筛选（成功/失败）
  - 按系统筛选

- 日志详情：
  - 请求时间
  - 请求方信息（IP/系统）
  - 请求参数（脱敏显示）
  - 响应状态
  - 响应数据
  - 执行耗时
  - 错误信息（如有）

- 统计分析：
  - 接口调用次数趋势
  - 成功率统计
  - 响应时间分布
  - Top错误类型

## 10. 内部管理操作流程示例

### 文档补录流程：
1. 文档管理员进入"文档管理-文档补录"
2. 选择单文件或批量上传
3. 填写文档信息和元数据
4. 关联客户代码
5. 提交上传
6. 系统自动生成哈希和版本记录
7. 文档自动对客户可见（或进入审核流程）

### 客户权限配置流程：
1. 客户管理员进入"客户管理-客户列表"
2. 找到目标客户，点击"编辑"
3. 进入"权限配置"标签页
4. 配置可访问的订单范围、产品范围、文档类型
5. 配置功能权限（下载、预览等）
6. 保存配置
7. 权限即时生效

### 同步任务执行流程：
1. 文档管理员进入"系统对接-同步任务管理"
2. 点击"立即执行"或等待定时触发
3. 系统调用源系统接口拉取文档
4. 解析文档和元数据
5. 生成哈希和版本记录
6. 建立维度关联
7. 更新同步任务状态
8. 发送同步结果通知
